# ♻️ EcoFind - Recycling Centre Locator

## 📋 Project Overview
A Java application that helps users find nearby recycling centres accepting specific materials. Designed for environmental sustainability in African communities.

## 🚀 How to Run

### **Option 1: Run in IntelliJ IDEA (Easiest)**
1. Open project in IntelliJ
2. Navigate to: `src/main/SimpleDialogGUI.java`
3. Right-click → "Run 'SimpleDialogGUI.main()'"
4. Follow the GUI prompts

### **Option 2: Command Line**
```bash
# Compile all files
cd src
javac -d ../out model/*.java service/*.java main/*.java

# Run GUI version
java -cp ../out main.SimpleDialogGUI
